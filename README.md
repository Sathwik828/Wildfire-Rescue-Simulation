# 🔥 Wildfire Rescue Simulation

A 3D third-person wildfire rescue game developed using Unity 6 and C#.

## 🎮 Project Overview
Play as a firefighter in a town threatened by spreading wildfires. Extinguish fires, rescue survivors, manage resources, and complete missions before time runs out.

## 🚀 Key Features
- Procedurally generated 3D environment
- Fire extinguishing with water spray
- Four survivor categories
- Survivor pickup and rescue system
- Health, stamina, water, and medkit management
- Easy, Normal, and Hard difficulty modes
- Progressive levels and night missions
- Weather, smoke, lighting, and audio effects
- Scoring and rescue combos

## 🛠️ Technologies
- Unity 6
- C#
- CharacterController
- Particle System
- Unity Input System
